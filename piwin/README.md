# Kiro for Piwin

Piwin provider extension for **Kiro API** (AWS CodeWhisperer/Q).

## Features
- **12+ Verified Models**: Claude Opus (4.8, 4.7), Claude Sonnet (4.6, 4.5, 4), Claude Haiku 4.5, Claude 3.7 Sonnet, DeepSeek V3/V3.1, GPT-5.6-Luna, and more.
- **Native Web OAuth**: Connect directly via Google, GitHub, or AWS Builder ID in your browser via PKCE localhost callback.
- **API Key & Local Credentials**: Supports `KIRO_API_KEY` (`ksk_...`) and automatic reuse of existing Kiro IDE / kiro-cli credentials.
- **Zero Runtime Dependencies**: Self-contained bundle compatible with Piwin immutable extension store.

Adapted from [mikeyobrien/pi-provider-kiro](https://github.com/mikeyobrien/pi-provider-kiro) v0.12.1.
